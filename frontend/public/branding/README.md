# Codex Squire brand assets

This logo suite is generated directly from the supplied `C:\Users\Sharma\Downloads\squire.svg`. The master is retained as `codex-squire-master.svg`; derived files keep its shield, scroll, proportions, gradients, navy frame, and page layout.

## Files

- `codex-squire-master.svg`: the supplied source SVG, preserved unchanged.
- `codex-squire-mark.svg`: transparent light-surface mark derived from the source.
- `codex-squire-mark-light.svg`: dark-surface mark with the navy frame reversed to light.
- `codex-squire-mark-ink.svg`: flat navy and paper version for print and neutral surfaces.
- `codex-squire-mark-white.svg`: one-color white version for dark surfaces.
- `codex-squire-icon.svg`: navy rounded application tile.
- `codex-squire-icon-light.svg`: light rounded application tile.
- `codex-squire-icon-white.svg`: complete square application icon on a pure white background, used for page branding, the browser favicon, and the desktop window icon.
- `codex-squire-icon-small.svg` and `codex-squire-icon-small-light.svg`: 32px icon versions.
- `codex-squire-lockup.svg` and `codex-squire-lockup-light.svg`: symbol plus Codex Squire wordmark.
- `codex-squire-preview.svg`: 1600 × 1040 identity board with the primary presentation mark, horizontal lockup, light/dark surfaces, application icons, exact 64/48/32/24/16px checks, and source palette.

## Usage

Use the transparent mark at 48px or larger. Use the white background icon for page branding, browser tabs, desktop window icons, and compact navigation where a stable light tile is required. Use the lockup only when a horizontal brand presentation is explicitly needed. Keep the shield behind the scroll and preserve the source aspect ratio.

Do not stretch, rotate, crop, redraw, or add effects to the shield and scroll. The master and all derived SVGs are self-contained and do not load external images or fonts.

The preview board intentionally uses outlined labels and an embedded copy of each SVG variant, so it remains portable when opened as a standalone file. The size-check rows show the actual rendered pixel sizes used by compact application surfaces.
